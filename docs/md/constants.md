# Constants

[← Index](../index.md)

- `CHAR_NORMALIZER` — Array que mapeia caracteres acentuados para suas versões normalizadas sem acento
- `STS_OK` — Sucesso (HTTP 200)
- `STS_CREATED` — Criado (HTTP 201)
- `STS_ACCEPTED` — Aceito para processamento assíncrono (HTTP 202)
- `STS_NO_CONTENT` — Sem conteúdo (HTTP 204)
- `STS_MOVED_PERMANENTLY` — Movido permanentemente (HTTP 301)
- `STS_FOUND` — Redirecionamento temporário (HTTP 302)
- `STS_REDIRECT` — Redirecionamento (HTTP 303)
- `STS_NOT_MODIFIED` — Não modificado, usar cache (HTTP 304)
- `STS_BAD_REQUEST` — Sintaxe incorreta (HTTP 400)
- `STS_UNAUTHORIZED` — Requer autenticação (HTTP 401)
- `STS_FORBIDDEN` — Proibido (HTTP 403)
- `STS_NOT_FOUND` — Não encontrado (HTTP 404)
- `STS_METHOD_NOT_ALLOWED` — Método não permitido (HTTP 405)
- `STS_CONFLICT` — Conflito com estado atual do recurso (HTTP 409)
- `STS_UNPROCESSABLE_ENTITY` — Entidade não processável (HTTP 422)
- `STS_TOO_MANY_REQUESTS` — Requisições em excesso (HTTP 429)
- `STS_INTERNAL_SERVER_ERROR` — Erro interno do servidor (HTTP 500)
- `STS_NOT_IMPLEMENTED` — Não implementado (HTTP 501)
- `STS_BAD_GATEWAY` — Gateway inválido (HTTP 502)
- `STS_SERVICE_UNAVAILABLE` — Serviço indisponível (HTTP 503)
- `STS_GATEWAY_TIMEOUT` — Timeout do gateway (HTTP 504)
- `IS_TERMINAL` — Indica se a execução atual está sendo feita via terminal CLI
