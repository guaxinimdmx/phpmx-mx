# PHPMX MX

Framework base para aplicações modernas em PHP

```bash
composer require phpmx/mx
./vendor/bin/mx install
```

Depois de instalar, rode

```bash
php mx
```

Se tudo tiver funcionado, você verá a logo do MX.
